# HadesScience · Personal Exploration Program

个人主页，采用低饱和深色配色、构成主义排版与航天图形。

站点：https://hadesscience.com/

## 发布

GitHub Pages 从 `main` 分支的根目录自动部署。修改网页后提交即可，无需安装依赖或构建。`.nojekyll` 保持静态文件原样发布。

- `index.html`：页面内容与导航。
- `styles.css`：响应式布局、矿物色调与动画。
- `script.js`：导航、面板切换、搜索、动效开关。
- `guestbook.js`：公开留言读取、刷新与分页。
- `assets/`：本地字体、字体许可证与图标。

## 留言板

留言保存在 [Guestbook Issue #1](https://github.com/HadesScience/hadesscience-personal-website/issues/1) 的评论中。

访客在页内编辑器中完成 GitHub 登录授权后，即可输入、预览和发表评论。备用列表可读取和刷新公开评论。站长可在 GitHub 中管理评论；访客可编辑、删除自己的评论。

页面不保存访问令牌、密码或其他密钥。留言按时间顺序分页读取，每页 20 条；评论正文按纯文本显示。公共 API 可能触发限流，届时页面提供重试说明与原始讨论入口。备用列表不需要额外服务器；页内编辑器使用下方说明的 Utterances GitHub App。

动画自动遵循系统的减少动态效果设置，页面不提供手动动效开关。首页通过主导航与向下阅读入口浏览内容。

本地字体为 Nimbus Sans Narrow Bold 子集；许可证位于 `assets/FONT-LICENSE.txt`。

## 页内留言编辑器

Utterances 嵌入编辑器绑定现有 Issue #1，主题为 `dark-blue`。访客完成 GitHub OAuth 授权后，可在网页中编辑、预览和提交留言。仓库所有者必须将 [Utterances GitHub App](https://github.com/apps/utterances) 安装到本仓库；权限为元数据只读、Issues 读写。

`guestbook-inline.js` 负责延迟加载编辑器、处理 OAuth 返回和连接失败重试。原生留言读取器保留在可展开的备用入口内。第三方脚本只从官方 `https://utteranc.es/client.js` 加载。


## 多语言

支持简体中文、统一繁体中文（`zh-Hant`）、英语、日语与俄语。首次访问按浏览器的语言偏好顺序匹配，均不支持时使用英语；`zh-TW`、`zh-HK`、`zh-MO` 和 `zh-Hant-*` 统一匹配同一份繁中翻译，显式 `Hans`/`Hant` 字形标记优先。页脚可手动切换并在本机保存偏好，也可选择重新跟随浏览器。

`i18n.js` 包含本地翻译与语言匹配逻辑，无需第三方翻译服务。翻译覆盖页面内容、无障碍标签、搜索提示、动效与留言连接状态；留言正文保留原文，Utterances 和 GitHub 自身界面由对应服务控制。

## 探索计划

四个方向：方块与机械、游戏与旅程、角色与重构、代码与工具。使用可键盘切换的四个标签页，展示 15 条项目或作品记录；手机端标签为两列排列，作品卡片为单列。所有新增内容均有五种语言文案。

Minecraft 项目为 Create Train、GuidedMod、Create Little Sorcery，链接到各自的 Modrinth 发布页。视频记录来自作者的 B 站公开投稿，包括 Create Train 实况、C2ME 对比、移动工厂、黄金十二宫还原，以及 Cyberpunk 2077 和 NieR:Automata 游戏记录。工具入口为 Browser Use for Codex 适配封装与 CC Switch Gemini Fixer，前者明确说明上游项目来源。

内容依据公开项目说明、B 站与 YouTube 投稿，以及 2026-10-18 核对的 X 创作记录整理；不将第三方模组、上游工具或 Fork 写成作者的独立原创项目，不将个人兴趣写成已完成作品。不硬编码下载量、粉丝数、最新版本或服务器在线状态。各卡片的链接是对应内容的公开来源。

每个方向通过「我在意的事」连接经历与作品：存档建设和游玩记录、人物与结局的余韵、建筑还原与角色模型实验、工具适配和修复。作品卡片分别归入对应方向，面板内入口跳转到相应集合，沿用无 URL 片段导航。兴趣和实验不会被表述为未来交付承诺或已发布成品；五种语言同步维护。

## 虚拟生活内容范围

个人介绍与探索计划仅记录数字世界中的经历：整合包与存档、铁路与移动机械、游戏旅程、建筑还原、AI 辅助角色模型实验，以及相关工具。作品链接区分游戏实况、通关感想与实验记录；模型实验不标记为已完成或可下载成品。铁路规模为视频拍摄时的记录，不代表存档当前状态。五种语言同步维护，现实生活经历不纳入此页面。
